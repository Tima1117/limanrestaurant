# Liman Restaurant landing page

One-page restaurant redesign in Next.js with English, Georgian, Russian and Turkish copy.

## Run

```bash
npm ci
npm run dev
```

Reservations open a prepared message in WhatsApp to the restaurant's published number. Sending and confirmation happen in WhatsApp; the site does not store bookings.

Gallery photos used for this design demo come from [Visit Ajara's Liman listing](https://visitajara.com/en/restaurants/287). Confirm usage rights with the restaurant or photographer before production use. The logo and other original photos come from [Liman Restaurant](https://limanrestaurant.ge/).
